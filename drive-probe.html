Does a folder picked with drive.file cascade to its contents?

Throwaway probe. It requests only drive.file — a non-sensitive scope, so no verification and no unverified-app warning — opens the Google Picker, and then asks Drive three questions about what that pick actually bought. Nothing is written, nothing is stored, and no file leaves this page.

Before you run it

  1. In the Cloud project, enable Google Drive API and Google Picker API.
  2. Create an API key (APIs & Services → Credentials). Restrict it to this site's referrer if you like. This is the Picker's "developer key" — it is not a secret in the password sense, but don't commit it.
  3. Paste it below and run the two tests in order.
